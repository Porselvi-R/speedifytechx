## 🏢 About

SpeedifyTechX is a creative digital studio specializing in modern web development, AI solutions, UI/UX design, and digital innovation. We transform businesses through cutting-edge technology solutions with a focus on creativity, performance, and user experience.

## 🚀 Features

- **Modern Design** - Silver ash & black theme with glassmorphism effects
- **Responsive** - Mobile-first design that works on all devices
- **Performance** - Optimized loading and smooth animations
- **Accessibility** - WCAG compliant with keyboard navigation
- **SEO Optimized** - Complete meta tags, structured data, and sitemap

## 📁 Project Structure

```
speedifytechx/
├── assets/          # Images, videos, and media files
├── css/            # Stylesheets (main, components, animations)
├── js/             # JavaScript files (main, animations, canvas)
├── docs/           # Project documentation
├── scripts/        # Python automation scripts
├── *.html          # Website pages
└── README.md       # This file
```

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript ES6+
- **Animation**: GSAP (GreenSock Animation Platform)
- **Icons**: Lucide Icons (SVG-based)
- **Backend**: Google Apps Script for forms
- **Build Tools**: Python automation scripts

## 📧 Contact Form Integration

The contact forms are integrated with Google Apps Script for seamless data collection:
- Automatic data validation
- Spam protection
- Direct spreadsheet integration
- Email notifications

## 🏃‍♂️ Quick Start

1. Clone or download the project
2. Open `index.html` in a web browser
3. For development, serve files through a local server:
   ```bash
   python -m http.server 3000
   # or
   npx serve .
   ```
