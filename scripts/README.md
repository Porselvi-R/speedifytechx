# Automation Scripts

This folder contains Python scripts for website maintenance and updates.

## Python Scripts:

- **add_projects.py** - Adds portfolio project cards to portfolio.html
- **add_hero_glow.py** - Adds visual glow effects to hero sections  
- **fix_hero_ui.py** - Standardizes hero section layouts across pages
- **build_team_marquee.py** - Creates animated team member carousel
- **standardize_hero.py** - Ensures consistent hero section structure
- **fix_code_and_grid.py** - Fixes HTML structure and grid patterns
- **apply_hover_and_dot.py** - Applies hover effects and design elements

## Usage:
Run Python scripts from the project root directory to maintain and update the website.
